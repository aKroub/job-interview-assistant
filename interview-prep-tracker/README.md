# interview-prep-tracker

The React application source for the Interview Prep Tracker.

See the [root README](../README.md) for full documentation on features, architecture, and usage.

## Quick start

```bash
nvm use 24
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build — must be 0 errors, 0 warnings
npm test -- --watchAll=false --verbose   # all tests must pass
```
